# Заказ из двух помещений: как разделить на пакеты

Коротко для склада. Полное описание — в «Обмен со складом — API Volento»
(docs/СКЛАД-API.md), разделы 4, 6, 7 и 8.

## Что изменилось

Раньше один заказ был всегда одной посылкой с одной наклейкой. Теперь,
если вещи заказа лежат в разных помещениях, заказ можно разделить на
пакеты: пакет на помещение. Покупателю это одна доставка: одна цена,
один трек, все пакеты он получает разом в одном пункте.

Кто не делит заказы, может ничего не менять: старые запросы работают
как раньше.

## Порядок

1. Забрали задание, собрали вещи в каждом помещении.
2. «Собрано» — вместо `pozicii` шлёте `pakety`:

   ```
   POST /sklad/zadaniya/{nomer}/sborka
   {
     "pakety": [
       { "sklad": "A", "pozicii": [ { "artikul": "5985-42/170", "kolichestvo": 1, "kody": ["..."] } ] },
       { "sklad": "B", "pozicii": [ { "artikul": "3147-46/176", "kolichestvo": 1, "kody": ["..."] } ] }
     ]
   }
   ```

   `sklad` — ваша метка помещения, любая. Коды маркировки — по коду на
   каждую штуку, как и было. Ответ: `"paketov": 2`.
3. Через пару минут заказ появляется в `GET /sklad/k-upakovke`. У него
   список `pakety`: номер пакета, помещение, что в нём лежит и ссылка на
   его наклейку.
4. Каждое помещение печатает свою наклейку:
   `GET /sklad/zadaniya/{nomer}/etiketka?paket=1` и `?paket=2`.
5. Упаковали пакет и наклеили наклейку — отмечаете:
   `POST /sklad/zadaniya/{nomer}/upakovano` с телом `{ "paket": 2 }`.
   Когда отмечены все пакеты, заказ уходит из списка.
6. Пакет из второго помещения привозите туда, откуда сдаёте посылки.
   В службу пакеты одного заказа сдаются вместе.

## Что важно

- На каждом пакете — своя наклейка. Чужую клеить нельзя: в службе пакеты
  одного заказа различают по наклейке.
- Заказ в постамат делить нельзя, на `pakety` из двух пакетов придёт
  `409`. Такой заказ собирайте одним пакетом.
- Пакетов в заказе — до 5.
- Собрали не всё — как и раньше: присылаете только собранное, заказ
  встаёт на паузу до решения покупателя.

## Как проверить

На тестовых заказах, ничего не отправляя на самом деле:

```
POST /sklad/proba/zakaz            { "kolichestva": [2, 1] }
POST /sklad/zadaniya/{nomer}/sborka   с "pakety"
GET  /sklad/k-upakovke?test=1
GET  /sklad/zadaniya/{nomer}/etiketka?paket=2
POST /sklad/zadaniya/{nomer}/upakovano   { "paket": 2 }, потом { "paket": 1 }
```

Тестовая наклейка — две страницы: «PLACE 1 OF 2» и «PLACE 2 OF 2».
