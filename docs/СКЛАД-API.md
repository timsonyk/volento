# Обмен со складом — API Volento

Памятка для программиста склада. Всё работает как FBS на Вайлдберризе и
Озоне: раз в минуту залить остатки, забрать новые сборочные задания, по
каждому ответить «соберём» или «отказ».

База: `https://api.slytn.ru`

---

## 1. Авторизация

Ключ в заголовке `X-Sklad-Key` на каждом запросе:

```
X-Sklad-Key: sk_sklad_…
```

Ключ выдаётся отдельно. Он не от админки: им доступны только четыре
действия ниже, больше ничего.

Дополнительно доступ запирается по списку IP — пришлите адреса, с
которых пойдут запросы.

Ответы при неудаче:

| Код | Что значит |
| --- | --- |
| 401 | ключа нет или он неверный |
| 403 | ключ верный, но адрес не в списке |
| 413 | пачка больше 2000 позиций — разбейте |
| 500 | у нас поломка, повторите через минуту |

---

## 2. Как мы опознаём позицию

Ключ — **артикул Озона**, тот самый `offer_id`, которым вы уже
пользуетесь, когда собираете озоновские поставки.

```
3149-46/170     артикул 3149, размер 46, рост 170
5110-38         юбки и рубашки — без роста
5390-38/40      блузы — составной размер «38, 40», роста нет
```

Присылать можно целиком или по частям — понимаем оба вида:

```json
{ "artikul": "3149-46/170" }
{ "model": "3149", "razmer": "46", "rost": "170" }   ← та же позиция
```

Баркоды и артикулы ВБ не нужны: у одного артикула их несколько и они
меняются.

## 3. Метод «залить остатки»

```
POST /sklad/ostatki
```

```json
{
  "ostatki": [
    { "artikul": "3149-46/170", "kolichestvo": 4 },
    { "artikul": "5110-38", "kolichestvo": 0 },
    { "model": "3149", "razmer": "48", "rost": "176", "kolichestvo": 12 }
  ]
}
```

**`kolichestvo` — то же число, что уходит на Озон**: сколько готовы
продать прямо сейчас. Свои брони вычитайте как привыкли, остальное мы
сделаем у себя. Никаких особых правил для нас нет.

Число абсолютное, не разница. Пропущенный запрос ничего не ломает —
следующий всё выправит.

Ответ:

```json
{
  "prinyato": 1998,
  "ne_nashli": [ { "artikul": "9999-44/170", "kolichestvo": 5 } ]
}
```

`ne_nashli` — позиции, которых нет в нашем каталоге. Это не ошибка: вы
торгуете шире. Но если список вдруг резко вырос — значит артикулы
разошлись, и обмен надо останавливать.

**Не больше 2000 позиций за раз.** Весь каталог (13 400 позиций) — семь
запросов, около 13 секунд.

### Пример: залить весь каталог

```js
const КЛЮЧ = "sk_sklad_…"
const ПАЧКА = 2000

async function залитьОстатки(позиции) {
  let принято = 0
  const неНашли = []

  for (let i = 0; i < позиции.length; i += ПАЧКА) {
    const кусок = позиции.slice(i, i + ПАЧКА)

    const ответ = await fetch("https://api.slytn.ru/sklad/ostatki", {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
        "X-Sklad-Key": КЛЮЧ,
      },
      body: JSON.stringify({ ostatki: кусок }),
    })

    if (!ответ.ok) {
      throw new Error(`остатки: ${ответ.status} ${await ответ.text()}`)
    }

    const { prinyato, ne_nashli } = await ответ.json()
    принято += prinyato
    неНашли.push(...ne_nashli)
  }

  return { принято, неНашли }
}
```

На Python:

```python
import requests

КЛЮЧ = "sk_sklad_…"
ПАЧКА = 2000

def залить_остатки(позиции):
    принято, не_нашли = 0, []

    for i in range(0, len(позиции), ПАЧКА):
        ответ = requests.post(
            "https://api.slytn.ru/sklad/ostatki",
            headers={"X-Sklad-Key": КЛЮЧ},
            json={"ostatki": позиции[i:i + ПАЧКА]},
            timeout=60,
        )
        ответ.raise_for_status()
        данные = ответ.json()
        принято += данные["prinyato"]
        не_нашли += данные["ne_nashli"]

    return принято, не_нашли
```

## 4. Метод «забрать новые задания»

```
GET /sklad/zadaniya
```

Отдаёт только то, за что вы ещё не брались. Подтвердили сборку —
задание пропало из списка само.

**Помнить, где остановились, не нужно.** Никаких меток времени: упали
ночью — наутро просто спросили снова.

```json
{
  "zadaniya": [
    {
      "nomer": "5",
      "id": "order_01M3HVS5GQ398MXM7NRCYYR3Q6",
      "sozdan": "2026-09-27T16:39:42.376Z",
      "pozicii": [
        {
          "artikul": "5985-42/170",
          "model": "5985", "razmer": "42", "rost": "170",
          "nazvanie": "Брюки палаццо классические, светло-серый",
          "kolichestvo": 1,
          "id_stroki": "ordli_01M3HVS5H1YA065KWC5F8K5MW6"
        }
      ],
      "dostavka": {
        "sposob": "pvz",
        "perevozchik": "yataxi",
        "punkt": {
          "id": "2165496",
          "nazvanie": "Пункт выдачи заказов Яндекс Маркета",
          "adres": "142279, Московская область, посёлок Оболенск, проспект Биологов, 1",
          "rezhim": "пн-вс: 09:00-21:00"
        },
        "gorod": "Серпухов"
      },
      "poluchatel": { "imya": "Елена Перова", "telefon": "+79001234567" }
    }
  ]
}
```

Параметр `limit` — сколько заданий отдать за раз, по умолчанию и максимум 100.

Заказ приходит уже оплаченным — можно сразу собирать.

`sposob` бывает `pvz` (везти в пункт выдачи, адрес в `punkt`) и
`kurier` (адрес получателя в `adres`).

## 5. Метод «взять в сборку»

```
POST /sklad/zadaniya/{nomer}/sborka
```

Тело можно пустое — соберём заказ целиком:

```json
{}
```

Либо построчно, если отгружаете часть:

```json
{ "pozicii": [ { "id_stroki": "ordli_…", "kolichestvo": 1 } ] }
```

Ответ:

```json
{ "nomer": "5", "sostoyanie": "v_sborke", "id_sborki": "ful_…" }
```

Повторный вызов — не ошибка. Если не получили наш ответ и позвонили
ещё раз, придёт `{"sostoyanie": "uzhe_v_sborke"}`, второй сборки мы не
заведём и остаток дважды не спишем.

## 6. Метод «отказ»

```
POST /sklad/zadaniya/{nomer}/otkaz
```

```json
{ "prichina": "net_na_sklade" }
```

Ответ: `{ "nomer": "5", "sostoyanie": "otmenen" }`

Резерв снимаем, деньги возвращаем, покупателю пишем сами — от вас
больше ничего не требуется.

Отказ нужен **только для одного случая**: последнюю пару купили
одновременно у нас и на другой площадке. Во всех остальных случаях
заказ до вас просто не дойдёт — почему, см. раздел 8.

После взятия в сборку отказаться нельзя: сначала отмените сборку
(ответим 409 с подсказкой).

## 7. Полный круг

```js
const КЛЮЧ = "sk_sklad_…"
const БАЗА = "https://api.slytn.ru"

const запрос = (путь, настройки = {}) =>
  fetch(БАЗА + путь, {
    ...настройки,
    headers: {
      "Content-Type": "application/json",
      "X-Sklad-Key": КЛЮЧ,
      ...(настройки.headers || {}),
    },
  })

async function круг() {
  // 1. остатки — то же, что уходит на Озон
  await залитьОстатки(собратьОстаткиИзСвоейБазы())

  // 2. новые задания
  const ответ = await запрос("/sklad/zadaniya")
  const { zadaniya } = await ответ.json()

  // 3. по каждому — решение
  for (const з of zadaniya) {
    const хватает = проверитьУСебя(з.pozicii)

    if (хватает) {
      забронироватьУСебя(з.pozicii)
      await запрос(`/sklad/zadaniya/${з.nomer}/sborka`, {
        method: "POST",
        body: "{}",
      })
    } else {
      await запрос(`/sklad/zadaniya/${з.nomer}/otkaz`, {
        method: "POST",
        body: JSON.stringify({ prichina: "net_na_sklade" }),
      })
    }
  }
}

setInterval(круг, 60_000)
```

Лимитов на частоту нет — сервер наш, можно хоть каждую минуту.

## 8. Как это устроено с нашей стороны

**Остатки.** У нас физический остаток и резерв под оформленные заказы
лежат порознь, а на витрине показывается разница. Ваши брони под наши
же заказы вы вычитаете у себя, поэтому мы к присланному числу
прибавляем свой резерв обратно — иначе одна и та же пара вычлась бы
дважды и пропала бы с витрины, лёжа на полке. Вам об этом думать не
надо: шлите как на Озон.

**Проверка перед оплатой.** Остатки приходят раз в минуту, и этой
минуты хватает, чтобы продать то, что за это время купили на другой
площадке. Поэтому прямо перед оплатой мы ещё раз спрашиваем остаток,
уже мимо кэша, и при нехватке до оплаты не пускаем — говорим человеку,
что товар разобрали. Возврат денег для покупателя хуже, чем честный
отказ минутой раньше.

Поэтому до вас доходят только те заказы, по которым товар был на месте
за секунду до оплаты. Отказ остаётся на один случай — гонку за
последней парой.

**Если вы молчите.** Оплаченный заказ, за который никто не взялся три
минуты, — повод для письма владельцу. Сам заказ мы не трогаем: отменять
лежащее на полке и обещать за вас то, чего нет, одинаково нельзя.

**Что смотреть после запуска:**

| Признак | Что значит |
| --- | --- |
| `ne_nashli` резко вырос | артикулы разошлись — остановить обмен |
| остатки перестали меняться | обмен встал, витрина показывает вчерашнее |
| отказов больше одного в день | остатки врут, а не «не повезло» |

---

## 9. Что нужно от вас

1. **IP-адреса**, с которых пойдут запросы.
2. **Подтвердить: шлёте тот же полный список, что на Озон** — все
   позиции, а не только те, что в наличии. В excel-выгрузке было 7 494
   позиции, а в нашем каталоге 13 269; если слать только первые, почти
   шесть тысяч позиций никогда не получат обновления.
3. **Подтвердить число остатка**: то же, что уходит на Озон, без
   пересчёта.
