# Обмен со складом — API Volento

## Как работает синхронизация

**Обновление остатков:** раз в минуту склад заливает актуальные цифры по всем SKU (артикулам типа `3149-46/170`). Число абсолютное — не "+3" или "−1", а "сейчас доступно 5 пар". Пропустили запрос — не страшно, следующий всё выправит.

**Оформление заказа:**
1. Человек добавил в корзину → видит остаток с задержкой до минуты
2. Нажал "Оплатить" → **проверка прямо сейчас**, мимо кэша:
   - Хватает → деньги списываются
   - Не хватает → показываем "пока оформляли, разобрали", деньги не берём
3. После оплаты → заказ падает в очередь
4. Склад забирает задания, видит все неразобранные заказы с адресами и составом
5. Склад отвечает: "беру в работу" → генерируем этикетку, списываем остаток, или "отказ" → возвращаем деньги

**Отказы редки:** проверка перед оплатой их отсекает. Отказ нужен только если в те же секунды, что шла оплата, ту же пару купили на другой площадке.

---

## Подключение

База: `https://api.slytn.ru`

Ключ выдаётся отдельно, прописать один раз в код.

Передавать в заголовке `X-Sklad-Key` на каждом запросе.

Ошибки: `401` — ключ неверный, `403` — адрес не в списке, `413` — пачка
больше 2000 позиций, `500` — наша поломка, повторить через минуту.

## Ключ позиции

**Артикул Озона** — тот самый `offer_id` из озоновских поставок:

```
3149-46/170   артикул, размер, рост
5110-38       юбки и рубашки — без роста
5390-38/40    блузы — составной размер «38, 40», роста нет
```

Можно слать целиком (`artikul`) или по частям (`model`, `razmer`,
`rost`) — понимаем оба вида. Баркоды и артикулы ВБ не нужны.

## 1. Залить остатки

```
POST /sklad/ostatki
```

```json
{
  "ostatki": [
    { "artikul": "3149-46/170", "kolichestvo": 4 },
    { "artikul": "5110-38", "kolichestvo": 0 },
    { "model": "3149", "razmer": "48", "rost": "176", "kolichestvo": 12 }
  ]
}
```

Ответ: `{ "prinyato": 1998, "ne_nashli": [ … ] }`

**`kolichestvo` — сколько готовы продать прямо сейчас**, за вычетом
отложенного под другие заказы. То же число, что уходит на Озон: там
оно уже посчитано, отдельная логика для нас не нужна.

Число абсолютное, не разница: пропущенный запрос ничего не ломает.
Не больше **2000 позиций** за раз — весь каталог это 7 запросов, 13 секунд.

`ne_nashli` — чего нет в нашем каталоге. Это нормально, вы торгуете
шире. Но резкий рост списка = артикулы разошлись, обмен остановить.

## 2. Забрать новые задания

```
GET /sklad/zadaniya
```

Отдаёт только то, за что вы ещё не брались; подтвердили сборку —
задание исчезло. Меток времени помнить не нужно.

```json
{
  "zadaniya": [{
    "nomer": "5",
    "sozdan": "2026-09-27T16:39:42.376Z",
    "pozicii": [{
      "artikul": "5985-42/170",
      "nazvanie": "Брюки палаццо классические, светло-серый",
      "kolichestvo": 1,
      "id_stroki": "ordli_01M3HVS5H1YA065KWC5F8K5MW6"
    }],
    "dostavka": {
      "sposob": "pvz",
      "perevozchik": "yataxi",
      "punkt": { "id": "2165496", "adres": "142279, МО, Оболенск, пр-т Биологов, 1" },
      "gorod": "Серпухов"
    },
    "poluchatel": { "imya": "Елена Перова", "telefon": "+79001234567" }
  }]
}
```

`sposob`: `pvz` — везти в пункт (адрес в `punkt`), `kurier` — адрес
получателя в `adres`. Заказ приходит оплаченным.

## 3. Взять в сборку

```
POST /sklad/zadaniya/{nomer}/sborka
{}
```

Ответ: `{ "sostoyanie": "v_sborke" }`. Повтор не ошибка — придёт
`uzhe_v_sborke`, второй сборки не заведём.

Можно построчно: `{ "pozicii": [{ "id_stroki": "ordli_…", "kolichestvo": 1 }] }`

## 4. Отказ

```
POST /sklad/zadaniya/{nomer}/otkaz
{ "prichina": "net_na_sklade" }
```

Резерв снимем, деньги вернём, покупателю напишем сами.

**Отказ нужен только для одного случая** — последнюю пару купили
одновременно у нас и на другой площадке. Прямо перед оплатой мы
проверяем остаток заново, поэтому обычная нехватка до вас не доходит.

После взятия в сборку отказаться нельзя — сначала отмените сборку.

## Цикл

```js
const КЛЮЧ = "sk_sklad_…"
const БАЗА = "https://api.slytn.ru"

const запрос = (путь, настройки = {}) =>
  fetch(БАЗА + путь, {
    ...настройки,
    headers: {
      "Content-Type": "application/json",
      "X-Sklad-Key": КЛЮЧ,
      ...(настройки.headers || {}),
    },
  })

async function круг() {
  const позиции = собратьОстаткиИзСвоейБазы()
  for (let i = 0; i < позиции.length; i += 2000) {
    await запрос("/sklad/ostatki", {
      method: "POST",
      body: JSON.stringify({ ostatki: позиции.slice(i, i + 2000) }),
    })
  }

  const { zadaniya } = await (await запрос("/sklad/zadaniya")).json()

  for (const з of zadaniya) {
    const путь = проверитьУСебя(з.pozicii)
      ? `/sklad/zadaniya/${з.nomer}/sborka`
      : `/sklad/zadaniya/${з.nomer}/otkaz`

    await запрос(путь, { method: "POST", body: "{}" })
  }
}

setInterval(круг, 60_000)
```

Лимитов на частоту нет.

## 5. Список товаров и сверка остатков

```
GET /sklad/ostatki-proverka?artikul=3149-46/170     одна позиция
GET /sklad/ostatki-proverka?offset=0                весь каталог, по 2000 за раз
```

Весь наш каталог: что за товар, сколько у нас записано сейчас — чтобы
сравнить со своей базой.

```json
{
  "ostatki": [
    { "artikul": "3149-46/170", "nazvanie": "Брюки классические прямые",
      "cvet": "чёрный", "razmer": "46", "rost": "170",
      "kolichestvo": 5, "v_rezerve": 1 },
    { "artikul": "5110-38", "nazvanie": "Юбка карандаш",
      "cvet": "бежевый", "razmer": "38", "rost": null,
      "kolichestvo": 0, "v_rezerve": 0 }
  ],
  "vsego": 13104, "offset": 0, "limit": 2000
}
```

`nazvanie` — наше название, без цвета. `cvet` — цвет. `razmer`, `rost` —
как на сайте; у юбок, блуз и рубашек роста нет — `null`.

`kolichestvo` — столько видит покупатель: ваше последнее число минус
заказы, пришедшие после него. `v_rezerve` — наши оплаченные заказы, которые вы ещё не
взяли в сборку. Следующая страница — `offset=2000`, и так до `vsego`.
Артикула нет у нас — `404`.
