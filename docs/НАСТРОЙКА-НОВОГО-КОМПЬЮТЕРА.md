## Шаг 6 — запуск

```bash
cd ~/Projects/Volento
claude --resume c5c36f17-decb-491e-a86f-258d9c3589dc
```

Откроется прежний разговор со всей историей проекта. Внутри него:

```
/remote-control Volento
```

Появится ссылка и QR-код: ссылку открывать в браузере на других компьютерах, QR сканировать телефоном.

Без истории, с чистого листа: `claude --remote-control Volento`.
